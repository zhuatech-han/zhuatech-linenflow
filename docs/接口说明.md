# LinenFlow HTTP接口

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。公开源码学习版，商用须书面授权。

同源路径 `/api`，JSON请求／响应，HttpOnly会话Cookie；先GET `/auth/csrf`获得header和token，所有写请求附该请求头。接口不能匿名操作业务。日期`YYYY-MM-DD`，月份`YYYY-MM`，金额最多两位小数，数量整数0–1000000，声明和配送行正数。

| 路径                                                                       | 方法与输入                                                                                           |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `/auth/login`、`/auth/me`、`/auth/logout`、`/auth/password`                | POST登录名／密码，GET当前账号，POST退出，POST旧密码／新密码                                          |
| `/options`                                                                 | GET当前范围的客户、品类、单价、部门及分类                                                            |
| `/catalog/{customers,items,rates}`                                         | POST创建；`/{id}` PUT编辑／DELETE删除未引用主数据                                                    |
| `/batches`                                                                 | GET search/status/page/size/sort；POST requestKey/customerId/serviceDate/note/lines(itemId,quantity) |
| `/batches/{id}`                                                            | GET完整详情；PUT相同草稿输入并附version；DELETE附version，仅DRAFT                                    |
| `/batches/{id}/commands/{action}`                                          | POST requestKey/version/note/reference/lines，动作见下文                                             |
| `/invoices`                                                                | GET同样查询参数；POST requestKey/customerId/period/note归集全部候选                                  |
| `/invoices/{id}`                                                           | GET账单、批次、款项及事件                                                                            |
| `/invoices/{id}/commands/{action}`                                         | POST requestKey/version/note/reference/amount/paymentId                                              |
| `/{batches,invoices}/{id}/report.json`                                     | GET权限内附件JSON，不加入品牌广告                                                                    |
| `/dashboard`、`/audit`                                                     | GET授权范围统计、最近500审计                                                                         |
| `/admin/{users,roles,departments,menus,permissions,dictionaries,settings}` | GET目录，POST可创建类型，`/{id}` PUT／DELETE受控维护                                                 |
| `/actuator/health`                                                         | 匿名GET，仅健康状态                                                                                  |

批次动作：submit/cancel、count、accept-count/reject-count、wash、inspect、dispatch、sign、return、complete。count每个批次行都传lineId和quantity；inspect每行传lineId及good/rewash/discard；dispatch仅正数行；sign传每个配送行实际签收数量，用reference定位本批次配送凭据；return传该笔全部配送行未签收件数，必须与发出减签收相等，含零行。其他动作需要非空note，不接收客户端状态、作者或时间。

账单动作：issue/cancel、confirm/dispute、pay/reverse。pay需要amount及唯一实际凭据，reverse需要原paymentId与不同的外部冲正凭据，操作人不能是原登记人。客户动作必须由绑定客户账号完成，工厂人员不能代签。

UUID须合法且精确重试同内容；不同内容复用返回409 REQUEST_KEY_REUSED，陈旧version返回409 STALE_VERSION。401认证失效，403权限／范围／岗位分离，400参数或数量守恒，404对象不存在，409状态、引用、余额或并发冲突。响应仅给安全code，不暴露SQL或凭证。

菜单和权限是预注册资源：可以编辑显示名称和菜单所需的已注册权限；不能新建虚构接口权限。账号customerId可为空，绑定客户时departmentId须与客户一致；密码只接受新明文输入并BCrypt散列，不返回密码或散列。管理员ALL且无客户绑定才可管理目录。
