# LinenFlow 架构与数据

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。公开源码学习版，商用须书面授权。

## 模块

Spring Security 同源会话入口、AccessService实时权限、AdminService身份目录、CatalogService酒店与单价、LaundryService洗涤数量状态、InvoiceService月度对账分别承担事务边界。Vue页面通过Nginx同源请求接口；MySQL8.4持久化；Flyway执行V1身份目录和V2业务。H2仅用于自动化集成测试，不能代替真实MySQL验收。

## 关系

部门→客户→客户约定价→布草品类；账号可选绑定一个客户。批次保存客户、部门、作者、日期、单价与品名快照。批次行保存声明、实收、合格、返洗、报损及实际签收数量。配送关联批次，配送行引用本批次行，不能跨单使用行号。月度账单关联一个客户和月份，invoice_batch保存归集批次及金额快照；批次invoice_id锁定有效归集。取消账单只释放有效占用，关联历史不删除。付款和独立冲正保持原始记录。

business_event保存对象、操作账号、服务端时间、说明和本次实际数量快照；audit_event只保存安全动作及对象，不保存密码或完整业务正文。command_record以UUID唯一键和SHA256绑定账号、命令、对象及精确输入，只在成功事务内记录。

## 状态与守恒

批次：DRAFT→DECLARED→COUNTED→ACCEPTED→WASHING→REWASH或READY→DELIVERED→COMPLETED。COUNTED可由酒店退回DECLARED。取消仅DRAFT／DECLARED；删除仅DRAFT。

配送：SENT→SIGNED或AWAITING_RETURN→RETURNED。签收数不超过发出数，拒收未解决前继续预留；退回核验确认所有未签收实物才释放。全部合格件签收且无未解决交接才DELIVERED，酒店另外确认完成。

账单：DRAFT→ISSUED→CONFIRMED→PAID；ISSUED可DISPUTED，确认前可取消释放批次。足额付款才PAID；独立全额冲正回CONFIRMED。零金额账单客户确认后直接PAID，不生成虚构款项。

## 并发与数据范围

所有管理和业务写入在READ_COMMITTED事务里锁总部行，锁后刷新账号、角色及密码指纹，之后检查数据范围、业务状态、版本与UUID。并发更新同单据最多一笔使用原版本成功，另一笔409；重新获取版本后还要重新检查可发量或余额。请求失败，业务、审计和幂等凭据全部回滚。

系统面向有界的小团队单实例，写入全局串行化；上限见README。酒店绑定优先于角色范围，不能以ALL突破客户隔离。工厂SELF仅访问本人编制或当前生产指派的批次、本人编制账单；ALL／DEPARTMENT按部门检查。角色或账号变更实时生效，改密码使原认证指纹失效。
