# LinenFlow 安全说明

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。公开源码学习版，商用须书面授权。

初始化密码随机生成，仅本机`.env`，生成权限0600、不显示、不覆盖。BCrypt12，密码最少12位含大小写及数字、最多72字节。Cookie HttpOnly/SameSite=Strict，HTTPS入口设置COOKIE_SECURE=true；写请求CSRF校验。连续登录失败8次限制5分钟，限制以源地址和登录名为键；代理部署需限制直接后端访问并正确配置受信转发，不能只靠应用限速抵御大规模攻击。

身份和权限每次从数据库读取；所有写入锁后重新验证，停用、撤权立即生效，密码变更撤销原会话指纹。绑定客户始终按所属酒店检查，管理员不能代酒店操作。质检、实物退回和收款冲正检查独立岗位。前端按钮只是提示，接口必须独立校验。

JPQL条件值绑定，实体类型和排序选项由代码固定；目录和对象数有上限。字段长度、件数、金额、状态、版本与UUID全部校验。只允许版本化迁移，JPA验证；历史关联外键与唯一约束保护记录。JSON导出通过同样读取权限，无品牌广告及凭证；不提供任意文件路径下载，不实现文件上传。

Nginx仅发布前端端口，禁止iframe嵌入，提供nosniff、same-origin引用策略及同源内容安全策略。正式部署需要HTTPS、可信网络、数据库独立账号、正确TLS验证、最小防火墙、离线备份与恢复演练。默认数据库连接针对Compose内部网络；连接外部MySQL应配置并验证受信TLS，不能沿用trust到公网数据库。

`.env`、output、测试状态、SQL备份、日志、依赖和构建产物不提交Git。自动扫描检查已知密钥格式、真实本机验收口令、品牌与许可；不是完整渗透测试或生产容量证明。不要在公开Issues／截图中发送真实酒店资料、凭证、Cookie或数据库备份。安全问题通过商业咨询微信私下反馈。
